# Save Our Wildlife — Multimedia Project

A responsive, accessible web page for a conservation organization's promotional video campaign.

## Project Structure

```
Multimedia/
├── index.html          # Main HTML page
├── css/
│   └── styles.css      # Stylesheet (responsive & accessible)
├── js/
│   └── video-controls.js  # Video show/hide and play controls
└── media/
    └── wildlife.mp4    # Promotional video (add your file here)
```
